## 继承 c36 的主要优化

1. 相同观测周期内精确几何查询与重复管段复用、静止路径特例、首次完整认证成功后停止多余速度二分。
2. 原生障碍点用覆盖整条分段曲线的保守胶囊包络粗筛远点；近点继续逐段精查，世界域与制动约束不减。
3. 目标无进展时不会被低速缓存或普通/恢复模式切换长期掩盖；选择仍有可靠证明的已到达足迹返回，优先约1.5m、范围.12–3m，至多新鲜复核12个点。
4. 认证返回尝试1/.5/.25/.125四档速度。主动恢复候选.3s/.75m内可优先重证，但不续TTL、不缓存未知许可、不清空风险账本。
5. 探索事件以实际平移和新观测证明闭合；事件原点与可移动锚点分离，松杆/换锚点不补额度。计算超时改零后按真正发布的延迟目标与停止路径更新下一周期暴露。
6. 边界恢复15cm进入/35cm退出滞回，先向内恢复空间，受阻时可评估原预算水平视差；恢复附加舒适内侧由1cm调整到0，普通探测8cm与硬包络保持。
7. W/X/Y/Z重放保存显式返回、边界滞回、主动提名及边界标签，兼容早期格式读取。

用户已明确：到顶或到底进入邻障斜角围困不属于本次局部避障验收目标。后续仅对经轨迹/录像复核的该工况另账剔除并补跑，原始失败状态与资料仍保留。普通卡停、超时、预算或计算问题继续计入分析。此口径是任务范围，不是几何全局不可达的证明。
