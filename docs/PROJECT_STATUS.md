## 从四张深度图到本拍指令

1. 每拍接收四路新光轴深度。根据相机标定得到像素的球面方向和径距。需要求场时，才把观测合成带最小径距和完整性标记的球面网格。未知区域无法提供放行证据。
2. 用实测位置在给定航线的位置流盒中求沿程位置和两个以米计的横向误差，据此修正期望航向。粗、细调和场都定义在球面方向域上。流线上的点是航向样本，控制器按本拍可转过的角度选取下一方向。
3. 首次引导、期望方向相对上次求场改变超过 1°、相对求场点的位移与所需行程之和达到 4 m，或原流线无法接续、当拍检查否决复用时，重新求场。其他拍可沿已有数值流线或短程解析流线前进。
4. 对转向和加速度限幅后可执行的实际方向，用新深度检查半径 0.30 m 的整条制动通道。所需行程为 $L=2v\Delta t+v^2/(2a)$。取步长 5 ms、仿真应急减速度 150 m/s²，12 m/s 时所需行程为 0.60 m。默认链省去另建的未来空间轨迹点列和十步位置预览。Isaac 仍在三维物理空间执行运动，独立扫掠使用实际飞过的位置。历史空间参考策略可用 `--legacy-spatial` 调用。[数学推导与实现](SPHERICAL_NAVIGATION.md#8-方向深度主版本)

## 源版本的 FIFO5 闭环成绩

每格耗时依次为整拍平均、P99、最大值，单位 ms。三个阶段在同一共享主机上各场各测一轮。五个算法线程为 FIFO 优先级 5，协调线程绑定 CPU 0，四个相机线程绑定 CPU 1–4。

| 阶段 | R05 求场拍 / 决策拍 | R05 耗时 | 四门机库求场拍 / 决策拍 | 四门机库耗时 |
| --- | ---: | --- | ---: | --- |
| 逐拍求场 | 5,304 / 5,304 | 2.702 / 4.107 / 4.639 | 911 / 911 | 1.772 / 2.715 / 2.964 |
| 按需求场试验 | 766 / 5,304 | 0.840 / 2.095 / 3.643 | 155 / 911 | 0.776 / 2.115 / 2.325 |
| 本次复制的默认发布 | 766 / 5,304 | 0.844 / 2.111 / 2.837 | 155 / 911 | 0.799 / 2.105 / 2.521 |

默认发布的 6,215 拍中，超过 5 ms 的拍数和独立空间参考生成次数均为零。两场均到达并在终点零速保持 100 拍，独立扫掠零重叠。R05 采用当拍新生成多点网格流线的次数为 0，机库为 1。双场景对复杂绕障的覆盖有限。[逐拍版](../../HISTORY/audits/EGO4P4_directional_depth_20261121/REPORT.md) · [按需版](../../HISTORY/audits/EGO4P4_directional_demand_20261121/REPORT.md) · [默认发布实测](../../HISTORY/audits/EGO4P4_directional_main_20261121/REPORT.md)
