## 模型与热路径

```text
新同步组四路原始Z → 原始3×3异常补值（四路常驻线程）
                 → 一次摘要扫描：原/补值Z摘要＋块minρ/原始minρ/有效数
                 → 固定块方向格查表
                 → 3m内块按距离档查膨胀模板 → 二维差分/前缀恢复
                 → 统一环视ρ、完整性和来源位 → Ω三态
每2ms：复用最新完整组；后续候选查询只读环视图
```

补值规则保持：只用本图原始3×3有限正邻居，原本有效像素不平滑，已补值不继续扩散。补值与摘要为两阶段，摘要的ρ和原有块/双图区域统计合并一次扫描。对有效原像素，raw和filled相同，复用同一次ρ乘法；异常raw的补值只提供保守观测，不能独自授予自由。

初始化预计算：

```text
b(u,v) = K⁻¹[u,v,1]ᵀ
c(u,v) = ||b(u,v)||
d_B(u,v) = R_BC*b / ||R_BC*b||
ρ(u,v) = Z(u,v)*c(u,v)
```

每像素c和固定方向格、每3×3块中心方向格、各环视节点中心对应的相机/原图块均提前保存。运行时代表方向不再计算Z*q+t、atan2或动态归格；朝向来自R_BC。边缘不足3×3的块继续保留。块最小ρ是逐有效像素ρ的最小值，**不是min_Z乘块中心系数**。

环视默认360×180个1°节点。每个节点中心在初始化用相机旋转和K查询对应原图块，运行时从该块取minρ；四路重叠可比较统一后的ρ并取小，不比较不同光轴的Z。静态视野无覆盖、全部无效或观测明显不完整的方向保持未知。全分辨率D、D_filled、K、真实T_BC、时间戳和b/d仍保留用于原始查询和记录；原图/补图查询仍是光轴Z，规划主查询明确返回ρ。

## 距离模板与0.10m包络

r=.10m、Lp=3m保持。每块minρ≤3m即参与保守排除，排除整块方向范围再加入r膨胀；不丢掉障碍数据。

```text
距离档 k = floor(ρ / 0.05m)，k=0…60
该档下界 = max(0, k*0.05m - 1e-9m)
膨胀半角 = asin(r/档下界)，档下界≤r时全方向保守处理
```

统一模板另加全部块中最大的视线半角、网格中心量化界及数值余量。块半角用含半像素边缘四角的最大视线偏差保守界预计算，不按当前深度做动态球体/角度计算。按“俯仰行×距离档”预计算模板，运行时由固定块格号定位、平移方位列即可；覆盖极点用全部方位角，±π接缝拆两段。

每个矩形只写4个差分位置，四路各自恢复覆盖，再合并相机来源位。无近块时沿用惰性清理。模板对所接受的虚拟模型保守；忽略真实光心平移是用户接受的模型近似，本版不再检验由此产生的实际近场盲区。

## 环视图、完整性与Ω

每节点保存统一minρ、观测相机位、原始完整相机位、障碍膨胀位和状态。原始完整指该来源块所有原始像素有限且>0；至少一路完整来源才可能提供通过依据。较近的其它来源可收紧ρ或施加障碍约束。

候选域是采集组机体系中的离散方向节点集合：

```text
Ω = { 节点 | 状态为 Available }
Unknown：未观测、缺失/不完整，或所需环视窗口缺证据
Unavailable：已有观测且被近障碍块膨胀模板排除
Available：未被排除，且3m位置的虚拟包络查询窗口中
           原始观测完整、统一最小ρ > 3m + 0.10m
```

模板可以延伸到原视野外；那些没有观测的节点仍为Unknown，不能因为未被障碍覆盖就当自由。环视图不是精确连续重渲染，节点值代表其静态对应块的最小ρ，范围采样和膨胀倾向保守。

为避免反复扫描，维护环视缺失计数前缀和、远观测完整性前缀和，以及8×8最小ρ摘要。Ω的固定3m查询窗口预计算；块完整性在摘要时缓存；只合并有静态视野来源的节点。候选位置`candidate(center_B)`按方向和距离档查询环视矩形，检查最小ρ与原始完整性，**不会再反投影四台真实相机或校验其平移/近裁面**。

API：

```cpp
builder.configure(cal, width, height, 1, 1, 16, 3, 5, true, true, true, true);
builder.process(frame, pixel_rays); // 默认虚拟中心；同组直接复用
LocalFieldView panorama(frame, builder.local_geometry());
auto node = panorama.panorama_cell(cell_id); // 可选ρ、相机/完整性位、三态、组身份
auto state = panorama.cell(cell_id);         // Ω节点状态与排除位
auto candidate = panorama.candidate(center_B); // 统一环视窗口查询
// sphere(center_B)保留兼容名称，虚拟模式只返回环视几何状态，不填真实相机投影。
```

原`block_ray`是带实际近裁面语义的光轴区间审计接口，在虚拟模式返回空，避免规划混用；`pixel`/`region`保留原始图像数值查询。显式`configure_real`及`configure_debug`用于历史模型审计，生产reader没有自动回退。

输入缓存保留同步序号/时间戳、观测/几何配置和外部坐标/参数/域/边界修订。模型改变需要重分配相应帧数组；同尺寸K/R重配会清除旧视野外的节点、ρ和完整性，不能遗留Available。数值深度相同时，只改变物理平移或近裁面信息不改变虚拟结果；身份仍更新以记录输入变化。

Ω表示已接受模型内的观测可用性。粗细调和场求解、最终域边界系数、参考曲线、反馈/限幅/响应后实际预测运动检查尚未实现；现有期望方向0～10m/s、2ms及20m/s²参考限幅接口保持，无运动输出。
