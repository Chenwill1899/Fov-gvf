2026-11-16 更新：P3已进行二维内禀坐标改造与严格缓存优化，三维飞行能力保持。新的曲线表示、法平面反馈、数值修复、测试及独立运行入口见 [当前实现](INTRINSIC_2D_PLANNING.md) 和 [本轮验证记录](../../../EGO4P3/docs/performance/planar_20261116/REPORT.md)。下文描述2026-11-13复制起点；其中“P3未构建”等仅是当时状态，旧耗时不作为新版本成绩。

## 1. 活动代码与完整链路

算法核心位于 `candidates/ldlt_parallel/new_controller/`。生产输入接线位于 `src/new_controller/src/navigation_input.cpp`，由 `src/new_controller/CMakeLists.txt` 链接核心候选。同包的 `depth_reader` 保留原输入诊断能力；候选自己的 CMake/README 中存在历史状态，不能替代当前生产接线说明。

```
四路深度图 + 相机标定 + 同时刻观测位姿
→ 四个常驻 C++ 相机线程：原始异常补值、4×4摘要、再3×3摘要、区域查询和本路方向数据
→ 环视融合、障碍包络、三态方向域 Ω
→ 起点连通分量、粗图聚合、粗层 LDLT、局部通道细层 LDLT
→ 球面势插值与正梯度、角域积分曲线 Q
→ 连续角曲线、曲率安排、世界系空间参考 γ
→ 原始深度连续占用管道检查
→ 固定参考跟踪与执行补偿
→ 滚动续证、条件重规划、连续切换和保护状态
```

四路并行仅指四相机预处理；融合、Ω、粗细求解和曲线等后续阶段在协调线程执行。后续正式性能运行要求五线程均读回 FIFO5，通常协调 CPU0、相机 CPU1～4；编译器、监督进程和整个仿真平台不整体提高实时优先级。此次复制没有运行这些线程。

## 2. 第1步：统一基础参数与时基

`config/base_step1.json`、`base_config.hpp` 及现有入口包含：三维速度模长12m/s、障碍范围4m、控制/读取目标5ms、物理步长5ms、相机200仿真Hz、仿真速度0.02倍、执行响应τ=0.10s、机体半径0.10m。执行能力校验150m/s²与旧参考命令限幅20m/s²为不同参数。内层补偿采用实际物理间隔，不将小步长强行按更大时间积分。

生产新运动输出仍关闭。R05 单独实验入口具有自己的执行与保护接线，不能据此将默认生产输出改记为已启用。

## 3. 四路输入、补值、摘要与方向域

- 四图按时间戳组成完整组，并关联观测时刻位姿、深度组身份、标定版本；缺路、失配、过期或未来输入按接口拒绝。
- `depth_preprocess.hpp` 对 NaN、Inf、零和负值使用同图原始3×3邻域中的有限正深度补值，无有效邻居则保持无效；不平滑原本有效像素，也不将新补值继续传播。原始有效性独立保留。
- `depth_camera_workers.hpp`、`depth_observations.hpp`、`image_hierarchy.hpp` 实现每路4×4摘要后再3×3摘要，记录均值、最小深度/射线距离、原始有效像素数与完整性；同时保留原图全分辨率区域查询。
- 射线按预计算内外参方向表转换：ρ=Z‖K⁻¹[u,v,1]ᵀ‖。虚拟共心环视保留相机旋转、忽略光心平移；真实安装位置保留供原图占用检查使用。
- `depth_virtual_panorama.hpp`、`depth_local_field.hpp` 用0.05m距离分档和保守角范围合并观测与排除近障碍；方向保留 Available、Unavailable、Unknown，Ω只取 Available。未覆盖、原始不完整或净空证据不足保持 Unknown。
- 0.30m为机体0.10m与误差目标0.20m的总包络。Ω与原图检查使用同一定义；不在已经膨胀的Ω上重复叠加0.30m。

## 4. 第2步：统一状态接口、粗细 LDLT 与角域 Q

`navigation_pipeline.hpp` 统一深度组、标定、观测仿真时间/位姿、实际位置/速度/时间、配置与参考版本、失败原因。状态与观测的默认最大龄期10ms仿真时间；组身份、位姿、配置及边界变化参与相应失效检查。

`navigation_config.hpp` 新增独立参考设计值80m/s²、最大曲率80/144=0.5556m⁻¹、最小半径1.80m、误差目标0.20m、接入偏差≤0.10m/≤5°、横向增益2s⁻¹、方向增益20s⁻¹、方向角速度/角加速度限值10rad/s与100rad/s²、内部补偿输入/变化率上限17m/s与450m/s²。

`harmonic_planner.hpp`、`harmonic_adaptive.hpp`、`grounded_system.hpp`、`trial_field_solver.hpp`、`sparse_trial_backend.cpp` 实现：

1. 实际运动方向优先提供起始方向，滚动接入使用旧参考切向。先搜索起点可达分量，再按期望方向确定可用出口；期望落在未知/障碍时不直接当作可通行。
2. 球面细网格1°、基础粗格3°，有限体积权重装配离散 Laplace–Beltrami 方程。高/低势标签为 Dirichlet 条件，域外/障碍/未知面无连接，局部侧边采用零通量条件。
3. 两层默认使用 Eigen SimplicialLDLT + AMD。后端仍保留 LLT、CHOLMOD、AMG、IC0、SGS 对照能力，不等于活动算法同时运行这些后端。
4. 严格缓存检查前移：节点连接、权重、边界与容差等完全一致，复用已验证结果；变化才重新装配/求解。矩阵条件允许时复用符号分析或分解，保持数值有效性和1e-7残差检查。
5. 4m节点精简：细层只求起点至出口的局部通道，默认扩三层、局部零通量边界，符合条件时可扩展重试。314是历史特定样本的节点数，不是所有场景固定节点数。扫描优化使用活动节点减少重复全网格遍历；没有采用全部临时缓冲改造作为当前默认优化。
6. `harmonic_direction_field.hpp` 插值势并求球面正梯度，`harmonic_curve.hpp` 用球面中点积分生成Q，初始最大步0.8°，失败缩步；核对经过格的覆盖、势进度、出口和停滞，未知/障碍不放行。

这里是在二维球面方向域上求标量调和势，再求其梯度并积分；它不等同于在物理三维体素中求解一个三维调和势。前向半球并集裁剪实验已回退，当前活动链为全向Ω和粗场、局部细通道。复制的前向实验文件仅保留历史参考。

## 5. 第3步：连续空间参考与整段占用检查

`spatial_reference.hpp` 将Q构造为C1连续球面曲线，并按累计转角重参数化；拒绝尖点及歧义对跖连接。采用曲率渐增—恒定—渐减轮廓，大转角 Lturn=ζe/κd+ℓr，小转角使用两段较短渐变；tr=0.10s、ℓr=1.20m。

由同一个连续函数得到 ζ(s)、切向 T(s)=RWB q(ζ(s)) 与位置 γ(s)=pa+∫T(u)du。复用位置积分端点，采用0.05m检索网格并插入接入位置；位置、切向和曲率保持同源。取消旧固定3m转向长度、固定4m参考弧长、正常末端强制零速及末端停车反向速度包络；4m限制观测距离。

`reference_occupancy.hpp` 对整段曲线构造保守覆盖球，包含曲率、积分/插值误差及0.30m包络；投回真实相机安装位置，用原始深度区域与近裁面记录证明覆盖。输出已观测净空、障碍、未知、超范围等状态；不只检查离散端点，也不将未观测的完整参考自动认证为可执行。复用缓存降低同图期望微动的开销。

## 6. 第4步：固定参考恒速跟踪和执行补偿

`fixed_reference_tracker.hpp` 复用位置表，在上次投影附近搜索并最多执行一次连续修正；解析计算方向前馈。外层5ms更新目标，内层按实际物理步长计算方向跟踪、角速度/角加速度限制及执行模型逆补偿，校验输入、变化率、执行加速度与跟踪误差。有效模型分支维持12m/s，失败返回保护状态。

已有12项C++测试及761步模型验证，最大横向误差上界0.140m、内部补偿输入峰值14.675m/s；覆盖90°、180°、三维和2.5ms内层步长。它们是来源版本的记录，本次未重跑。

## 7. 第5步：滚动续证、连续切换与保护

`rolling_navigation.hpp` 每个新深度组先为现有参考从当前位置附近续证到前方0.35m；未知/障碍/超范围截断证据前缀。净空够下一步且期望变化不超过1°时跳过求场与曲线重建。重复状态不重复推进控制；漏物理步、时钟回退、证据失效等进入保护或复位。

参考切换前核对位置、切向、曲率和接入净空，保留累计进度、角速度和前一补偿输入；接不上则保留仍有有效证据的旧参考。覆盖球凸性用于验证一步两端及其直线扫掠；无有效证明不输出正常恒速候选。ROS提供 `--track-fixed` / `--track-rolling` 诊断接线，默认无运动发布。

已有13项CTest、重复组/中断/时钟回退与恢复检查。1400步模型中12次求场、最大误差上界0.066m；急三维状态触发保护。真实原图回放因近场证据不足进入保护，没有把模型几何证据当作真实原图通行证明。

## 8. R05 Isaac 单独引导飞行实现

`docs/performance/r05_flight_20261107/` 保留 controller.cpp、版本源码、运行适配与审计程序。所需 anchor_include 也保留。历史路线仅提供几何引导，四路实时深度与当前C++控制参与执行；出生点认证和独立碰撞复核使用地图。实验含加减速、引导分支、静态净空证据和终点停稳处理，不能把整条飞行称为全程第5步恒速跟踪或纯终点自主导航。

该入口可选 Isaac 特有的 +Inf 无命中适配：确认远裁面后映射到4.5m，查询仍截在4m；NaN、负无穷、零及负值不因此放行。此开关不改变通用原始无效深度的默认规则。

历史最终飞行41.50仿真秒、308.925m、扫掠零碰撞、终点误差0.169m、停稳速度0。视频为已验收轨迹在原场景重新渲染的回放，并非录制时重新完整飞通的证据。纯终点自主脱困、持续恒速和在线FIFO5全程计时仍未验收。
