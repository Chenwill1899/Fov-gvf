# 实际速度与期望方向的前向半球并集

2026-11-06 21:59 +0800：已接入独立C++候选，完成构建与离线正确性检查。**本轮没有运行FIFO性能测试，也没有启动新Isaac仿真或运动；耗时收益等待用户执行文末指令。** 原4m精简版3.173ms属于上一轮基线，不当成本轮成绩。

## 当前运行链

`ForwardFieldPipeline`使用同一份图像和状态依次执行：方向范围准备 → 四路常驻线程中的补值／4×4摘要／原始区域数据／方向数据 → 串行合并／Ω → 连通分量 → 粗场 → 原3层局部细通道／.8°曲线。求解和曲线仍在一个协调线程，四路线程仅负责各自相机。

名义保留规则：`dot(ray_direction, actual_velocity_unit)>=0 OR dot(ray_direction, desired_unit)>=0`。实际速度读取`BodyState.v_B`，world速度由既有R_WB转到body；期望方向单独使用`DesiredMotion.d_desired`。使用相机R_BC与像素射线查表选块，不按相机名字保留两张图，不以机头朝向代替实际运动。

## 邻域、膨胀与时间余量

- 补值目标按4×4块掩码选择，但3×3邻域始终读本帧完整原始D；不读新补值作邻居。被跳过的filled位置清为NaN，摘要无效，不沿用上帧后方结果。
- 保留四张完整原图和同步来源。每个新图像组先对原图做一次SIMD有限正值最小深度扫描；与预计算系数下界给出所有可能补值／径向值的保守下界。沿用原.05m档和.10m膨胀矩形模板，反查哪些图像块的最大可能影响范围会碰到保留核心；这些块必须处理，即使在名义半球之外。近到机体半径时可能恢复全部图像处理。
- 核心域所有4m查询窗口的来源块也保留，二级图像摘要的3×3组完整保留。未裁剪的一整台相机仍走原始整图补值快路径，避免给最慢一路添加逐块修补开销。
- 默认更新预算10ms，以150m/s²能力和实际速度建立方向变化锥`asin(150*delay/|v|)`，再加1°网格边缘余量。12m/s时运动余量约7.18°，不是只有名义180°。若该比值≥1、零速、无效实际速度、缺期望方向、状态与图像时间戳不一致或方向并集加余量已经覆盖全向，则使用全向。
- 单次裁剪计算超过10ms预算会重做全向，费用计入总耗时。10ms是当前假定的更新延迟上界，未来在线接线须包含实际观测／状态／执行延迟，不能把本轮静止回放当成动态延迟认证。

图像区域的控制掩码、Ω、连通分量和粗场贯穿同一裁剪核心。裁剪外Ω为Unknown，数值guard数据只用于边缘查询，不授予后方自由；固定网格、查询前缀等预分配数组仍保留，不能假定全部工作量正好减半。

## q0、出口和全向重做

- 有非零实际速度时，q0优先为实际速度方向；不会让参考切线或摇杆期望方向覆盖它。零速时不归一化零向量，选择范围保持全向；入口方向优先保留最近实际运动方向（转过世界系再回到当前body），无运动历史时显式使用起步期望方向，元数据分别记录来源。
- 期望方向只决定出口搜索。原始Unknown／障碍仍保持原判定；不可用目标按当前可用连通分量选择出口，不直接当作Available。
- 裁剪求解失败、没有有效Exit、一个已知Available的目标因裁剪而断连、裁剪出口不能向目标取得进展，或预算超限时，重新用本帧原始四图做全向预处理与求解。没有重用旧后方摘要。全向仍不可行则保留失败，不伪造曲线。
- mask／支持块变化进入scope revision、输入快照和求场缓存失效；同一图像组中的方向变化会重新建立必要数据。掩码实际上相同的微小方向变化允许复用，当前q0／期望仍按现有精确意图规则更新曲线。

绕后回退测试暴露了旧局部Neumann通道的Low点可能落在绕行通道中段，使入口支路势场变平。已保留普通用例原Low，仅当它远离实际入口且落在内部路径时，将接地点移到入口附近、与第一条BFS边相反的一侧。仍为单点Low／原Exit／Neumann侧边，原3层、.8°、1e-7精度及逐段覆盖保持，参数revision 3→4。此处是有意修正边界位置，不宣称所有细势／曲线与旧版等价。
