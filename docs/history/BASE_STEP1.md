## 用户执行FIFO验收

```bash
sudo /usr/bin/python3 -I /home/starry/isaac-data/EGO4P2/scripts/run_step1_fifo.py
```

1. 验证当前源／安装身份、Python与C++参数一致。
2. 运行.2s仿真窗口、.02倍的静止只读传感器检查。仿真与ROS保持普通用户／普通调度；只给已核验的reader进程RTPRIO5，在门控后四路工作线程CPU1～4及读取线程CPU0自行设FIFO5。监视实际五线程策略／优先级／亲和性；没有权限、设置失败或读回不符即停止，无自动普通回退。
3. 核对实际physics/render dt、每次timeline增量与PhysX回调、四路时间戳间隔、读取绝对5ms节拍；报告真实墙钟读取抖动／丢间隔，不能把名义周期当实测间隔。仅记录PhysX事件，不开启重型CPU profiler。初末位置一致且运动发布者0。
4. 三轮独立LDLT候选离线FIFO5回放，每轮200次/7case/3mode，共12600计时记录；其中两份真实可用锚点完整冷算1200条。严格缓存前移与四路预处理并行保留，粗细求解／曲线仍单线程。以5ms绝对释放，错过周期跳过而非赶算，保存compute／release delay／response及跳过次数。冷算包含四路图像预处理、串行合并／Ω、捕获、两层场和曲线；另两种模式使用已备输入，不能称新深度完整处理。
5. 输出`RESULT_DIR=...`与`summary.json`：均值、P99、最大、>5ms次数、跳过周期。用户将RESULT_DIR发回后才评估新配置性能。

当前ROS主包仍为步骤1～7／3×3摘要，独立候选仍4×4后3×3并包含LDLT；本步不把两者冒充已经在线合线。该命令将其分阶段验证，无运动控制，不改变全局实时设置，不保存sudo凭据。旧`run_reader_privileged_check.py`现在显式转入此入口，不再运行P0／CPU5／FIFO10旧协议。当前默认`run_ldlt_candidate_benchmark.py`改用5ms离线释放；显式冻结源码／独立驱动仍按其历史协议解释。
