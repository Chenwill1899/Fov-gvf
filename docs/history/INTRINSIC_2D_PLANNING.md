## 当前链路

四路原始深度 → 原始完整性、4×4/3×3摘要、全向 Ω → 球面二维调和场 → 二维局部坐标中的连续方向曲线 → 三维空间参考与原图连续管道检查 → 二维法平面反馈 → 三维执行补偿与滚动续证。

原算法已经在二维球面 S² 上求调和势，没有一个三维体素调和场可直接删去一维。空间参考 γ(s) 是单个弧长参数对应的三维位置；投影也是一维参数搜索。本轮把后续方向插值、弧长度量和横向反馈显式写成二维内禀计算。三维坐标用于传感器外参、物理轨迹输出、碰撞证据及执行模型，不能删除，否则会丢失爬升、下降或真实净空信息。

## 方向曲线的二维表示

`harmonic_direction_field.hpp` 在非极区直接用二维正交梯度分量 `(φ_α/cosβ,φ_β)` 计算范数和坐标速度，取消先组合三维梯度再点乘拆回的重复工作。需要输出时仍恢复三维梯度。84°～86°极区混合保留原支路；接近零梯度判据时使用原计算消除舍入造成的分支歧义。

`spatial_reference.hpp` 为每段连续球面曲线建立局部正交基 `(e₁,e₂,n)`。原 Hermite/Bezier 控制点 `bᵢ` 保留。令固定权重 `wᵢ=bᵢ·n>0`，两个图坐标为 `xᵢ=(bᵢ·e₁)/wᵢ`、`yᵢ=(bᵢ·e₂)/wᵢ`。Horner 法计算固定有理曲线的齐次多项式 `X,Y,W`，得到二维坐标 `(x,y)=(X/W,Y/W)`。

三维方向只在需要输出或验证时恢复：

`q=(n+x e₁+y e₂)/sqrt(1+x²+y²)`。

球面弧长的二维度量为：

`|dq/du|=sqrt(x'²+y'²+(x y'−y x')²)/(1+x²+y²)`。

程序用其等价齐次形式，避免每个高斯积分点都构造三维方向、三维导数及其范数。`W` 是固定有理曲线权重，不是第三个规划自由度。每段重建局部图，经过世界坐标极点、方位角接缝或改变飞行高度不受固定图奇点限制。

这保持原曲线形状，未另换插值模型。原始控制点继续用于整段方向域证书；原 C1 连续性、曲率安排和位置积分误差界保持。有限精度差异由独立旧式 Bernstein 表达核对。三维位置积分仍按同一曲线执行，不能将几何表示优化解释成取消实际空间验证。

额外修复了原 SLERP 的极小角问题：旧代码先构造长度约为 `sinθ` 的向量，再使用针对无效方向的 `1e-9` 阈值归一化，却未检查失败。现在使用除以 `sinθ` 的归一化权重，并检查返回值；已知非零短弦按真实范数归一化。原 `1e-11` 小角去重和真正尖点/歧义对跖拒绝保持，合法小弧不再因幅值缩小被误判为无效方向。

## 二维横向反馈

`fixed_reference_tracker.hpp` 在当前单位切向 `T` 的法平面内建立稳定正交基 `(N₁,N₂)`。横向误差为两个标量 `e=(N₁·r,N₂·r)`，反馈为 `w₂=−kₑ e`；用二维范数分配切向速度预算，再恢复 `w=N₁ w₂₁+N₂ w₂₂`。

这与原来的 `(I−TTᵀ)r` 等价。法平面随路径旋转，不是固定世界平面；爬升、下降及三维弯曲继续可用。三维方向控制、曲率前馈和执行响应补偿保留。没有跨周期积分局部坐标基，因此基的表示分支变化不会产生额外控制跳变。该项是表示降维，是否单独加速以实测为准。

## 严格复用和证据边界

- 同一完整观测身份复用已捕获的输入，省去再次验证/复制块摘要和全 Ω。身份含组、载荷修订、标定和各路时戳；改变身份、失败、重配置或时钟复位后重新捕获。滚动周期跳过求场不等于已捕获新组。
- 位置平移不参与观测机体系的角域方程。保持 Ω、坐标旋转和方向意图相同，可以复用角域解；空间放置版本仍更新，原图管道证据仍重新检查。
- 方向域证书对完全相同的 Ω 复用二维前缀计数表，每条新曲线仍独立验证。比较完整状态字节和网格尺寸/角步长，不只比较哈希。任何 Unknown/障碍变化都会使表失效。
- 原图球查询发现疑障碍即可返回，因为后续相机的净空证据不能覆盖障碍结论。净空仍要求完整原始像素及真实相机近裁面，补值和部分相机覆盖不授予自由。
