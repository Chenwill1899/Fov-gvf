# 当前 P3 的 Isaac Sim 闭环入口

状态：四个 Isaac 测试场景的实际闭环正确性已通过，默认 .02 倍 GUI 升高飞行已目视验证；正式五线程 FIFO5 验证仍待本机 sudo 认证。

## 启动

```bash
sudo /usr/bin/python3 -I /home/starry/isaac-data/EGO4P3/scripts/run_isaac_closed_loop.py --scenario climb
```

默认显示 Isaac Sim 窗口，仿真步长 5 ms、时间倍率 0.02。四路相机工作线程在 CPU1～4，协调与规划在 CPU0，五个 C++ 算法线程均要求 FIFO5；仿真器保持非实时调度，主线程和启动器为 OTHER。权限或实际线程读回失败即停止。结果保存在终端打印的 `RESULT_DIR`。

只读预检：

```bash
/usr/bin/python3 -I /home/starry/isaac-data/EGO4P3/scripts/run_isaac_closed_loop.py --check
```

改动源码后重建并验证身份：

```bash
/usr/bin/python3 -I /home/starry/isaac-data/EGO4P3/scripts/build_isaac_closed_loop.py --tests
```

场景可选 `straight`、`climb`、`offset_obstacle`、`blocking_obstacle`。`--headless` 关闭可视窗口；`--steps N` 是有界调试，达到步数不能视为到达目标。默认 `climb` 的目标比起点高 3 m；`blocking_obstacle` 的障碍真实阻断起终点直线。

开发阶段可显式使用 `--correctness-only` 作为普通调度功能检查，其计算耗时不能标为正式 FIFO 性能。

## 连接与模型

新增应用直接编译当前 P3 的 `NavigationPipeline`，使用严格粗图缓存、粗拓扑证书和局部细场 LDLT。方向、曲线及法平面反馈继续使用二维内禀坐标，状态、相机姿态和执行速度仍在三维世界中。没有固定飞行高度。

每一拍由 Isaac 渲染四路 320×240 原始光轴深度，连同当前实际位置、速度和姿态发送给 C++。C++ 生成当前参考上的控制输入，Isaac 用既有一阶速度响应执行，再把新状态反馈。没有旧控制器、预设引导路线或多轴直行回退。

每拍显式推进一次真实物理步，再同步显示时间并渲染；传感器绝对时间必须与实际物理时间一致。初始化的 8 个物理步单独记录，飞行从预热后的逻辑 t=0 开始。

为支持从静止开始和到达停车，独立仿真应用增加标量速度调节与目标制动。正常非零控制必须来自已接受空间参考的二维法平面反馈。执行前检查当前一步以及完整制动路径的连续覆盖球；证据不足时只能执行仍有证书的制动或停止本次运行。

场景使用半径 0.10 m 的球形机体和四个同心相机，近裁面 0.10 m、远裁面 50 m。相机内外参从实际 USD 读取；整数像素坐标采用 `(width-1)/2, (height-1)/2` 主点，匹配实际渲染采样中心。原始 NaN/Inf 不变为自由空间。

出生处 2 m 静态净空球由场景几何验证；之后只保留有限的实际历史深度。当前观测的障碍和超范围否决优先。场景几何用于出生证书和独立碰撞审计，不参与航向选择。此历史证据策略仅适用于当前静态测试场景。

这是带真实深度渲染的一阶运动学闭环，尚不是四旋翼刚体、推力、电机和姿态动力学验证。5 ms 是仿真步长；现实运行速度及算法计算耗时分开记录，不能据此声称现实时间 200 Hz 或硬实时达标。

## 证据

| 场景 | 仿真秒 | 终点误差 m | 最小机体扫掠净空 m |
|---|---:|---:|---:|
| 直行 | 2.425 | 0.090 | 3.900 |
| 升高 3 m（GUI） | 2.445 | 0.090 | 0.699 |
| 正面阻断障碍 | 3.765 | 0.110 | 0.300 |
| 偏置障碍与三维目标 | 3.000 | 0.103 | 0.263 |

四场景均到达、最终零速并连续保持 .5 仿真秒，独立扫掠碰撞和仿真保护干预均为 0。这些是显式普通调度功能检查，不能写为 FIFO 性能。完整证据、失败记录、实际航迹和截图见 [本轮报告](../../../EGO4P3/docs/performance/isaac_closed_loop_20261117/REPORT.md)。

每次运行保存场景、参数、源码和二进制身份、实际线程调度、相机标定、首组原始深度、逐拍状态及控制 CSV 和结果；GUI 运行另保存截图。独立审计重新计算运动响应、三维速度与加速度、整段扫掠净空、IPC 时序、终点误差和连续停车保持，不单独依赖仿真器的 `success` 字段。

本轮备份、失败尝试、构建和验证详情保存在 [实验目录](../performance/isaac_closed_loop_20261117)。原生产安装和默认 `motion_output_enabled=false` 保留；运动授权限定在用户要求的新增仿真入口。
