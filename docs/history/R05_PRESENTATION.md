# R05 统一跟拍、回放和 ARL 模型

2026-11-18：P3 的R05入口采用 EGO2P6 的 **NTNU ARL-Robot-1** 新外观；镜头及回放按原R05视频恢复。原蓝色简模保存在源USD中，运行时仅在session层替换，场景文件、相机安装、算法参数及执行模型没有被改写。

## 实时仿真

启动命令保持：

```bash
sudo /usr/bin/python3 -I /home/starry/isaac-data/EGO4P3/scripts/run_r05_model.py
```

默认五线程FIFO5、5ms物理步长、0.02倍仿真节拍。需要更快的测试节拍可加 `--time-scale 1`。正式运行仍需读回五个算法线程的FIFO5；权限不足不降级。

窗口使用1600×900布局、25mm焦距、36×20.25mm画幅。实时镜头按当前机身偏航，在168个后侧候选位置中选择避挡视点并作因果平滑，显示同款标题、速度、高度、仿真时间、状态和路线图。实时HUD的路线图表示几何引导，里程来自实际状态累加；它不参与控制和净空认证。

离线回放拥有整段已知轨迹，使用原视频最终版的动态规划与对称高斯平滑；实时运行不知道未来实际状态，因此采用同组候选和避挡偏好的因果跟拍。两者保持同款镜头构图，不能把实时镜头解释成读取未来控制状态。

## 回放及导出

```bash
/usr/bin/python3 -I /home/starry/isaac-data/EGO4P3/scripts/replay_r05_model.py
```

默认选择P3中最近一份**独立审计通过且ARRIVED**的R05记录，按记录的真实位置和偏航在Isaac中重新渲染。它不启动规划器、不发布运动，也不把历史轨迹当作本轮新飞行。

- 指定记录：`--run /home/starry/isaac-data/EGO4P3/docs/performance/r05_model_sync_20261117/run_...`。
- 五帧预览：`--preview`。
- 核对新外观对四路深度的影响：`--validate-depth`。
- 输出目录及视频：终端打印的 `OUTPUT_DIR`，原有录像保留。

视频采用与原片相同的1600×900、30fps、H.264编码、原信息面板和路径图位置。41.50s飞行记录抽取1246帧，再保留60帧结尾，共1306帧/43.533s；逐帧选择最接近的5ms状态，最大采样时间差1.667ms。

## 外观替换范围

`scenes/robots/arl_robot_1/visual.usdc`、provenance和BSD许可证从EGO2P6逐字节复制。新模型保留原尺寸和材质，约36.9万三角面。旧Body/Arm/Motor/Propeller仅在session层停用，四个相机及机体状态节点保留，未引入P6的旧控制器、刚体、关节或碰撞体。

这次更换的是**外观资产**。原P3一阶运动学执行模型、0.10m控制机体半径和0.30m规划管道保持；P6资产中的0.48m物理半径没有自动写入P3。本次不构成完整ARL机体外形或四旋翼动力学的碰撞验收。

入口共用 `apps/r05_model/presentation.py`。场景根层/占据文件原SHA保持；新模型只通过session层呈现。参考视频、P2/P6资产和所有旧飞行记录保留。
