## 实际调度及权限

| 线程 | CPU | 必须读回 |
| --- | --- | --- |
| 相机0～3预处理 | 1、2、3、4 | 每路SCHED_FIFO／5 |
| 协调、域构造、两层LDLT及曲线 | 0 | SCHED_FIFO／5 |

线程池先在普通策略下初始化，C++入口在任何测量前将四个worker和协调线程设为FIFO5并读回。权限不足、设置失败或读回不符直接退出；启动器还检查结果元数据，并在运行中核对线程的策略、优先级、CPU和用户身份。不会静默回退普通调度。

`sudo`仅供普通调度的Python监督进程为本次子进程设置资源上限。编译器和算法实际降为项目普通用户运行；算法读回UID1000、有效能力0。子进程RTPRIO上限5、连续实时CPU软／硬限制5／6秒、总CPU软／硬限制90／95秒、墙钟超时180秒，退出即消失。CPU5可供普通监督进程使用。不修改全局调度、实时预算、持久能力或sudo配置，不保存认证凭据。FIFO提高相对普通任务的优先级，不代表独占核心。

不执行算法的检查方式：

```bash
python3 -I /home/starry/isaac-data/EGO4P2/scripts/run_ldlt_candidate_benchmark.py --check
```

无权限时如只需编译，可显式加`--build-only`。`--scheduler normal`只保留为用户明确要求的诊断对照，默认不使用；其结果不得标作FIFO性能。
