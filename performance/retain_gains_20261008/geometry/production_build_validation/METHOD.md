# 主入口构建产物复验：计时前冻结

首次局部实验的独立链接重放器与主入口构建重放器二进制SHA不同。为使收益结论对应实际将部署的构建，本阶段只替换为冻结controllers/v2、v4、combined中的paper_replay，baseline仍取本轮baseline/paper_replay。复制后的SHA与原主入口产物一致，源码从各自冻结archive提取并核对；全部paper_guidance源与首次试验完全相同，其他pc_gvf源与baseline相同。算法、边界、证据顺序和预算没有更改。

使用首次试验完全相同的37输入、8批四变体逐帧平衡顺序、统计方法和4项必要增量比较，另报告组合对baseline。每批全部输入是独立重复单位；置信区间和方向检验方法见plan.json。全部原始输出逐字节比较，不覆盖或合并首次试验的结果，报告任何分组退化。没有10%最小收益限制。

所有冻结检查在首次计时前完成；必须收到root明确CPU窗口开放消息才开始计时。本阶段不编译、不改任何生产源码，也不重跑额外几何微基准。
