# 人工全向连续候选：实现与独立机制检查

候选已完成机制检查及三对真实 Isaac jitter 探索，**未达预登记收益门槛，决定淘汰**；生产回退由主线程统一执行，候选源码和全部失败结果保留。未继续增强原始输入滤波，不改变松手、物理动力学或最终完整运动/制动认证。

## 依据

前两轮已证明原始意图更平滑不能推出实际避障更平滑。实际4–8s绕障中，输入TV降低而提案和执行目标TV增加；小角.12s保持覆盖不到主要跳变，已否决。统一接收样本只修复执行数据新鲜度，不作为避障算法本身收益。

继续读取当前全向代码发现：候选格点水平2°、俯仰5°，angular_room用最近格点取值；其-.55×角域余量评分对非格点方向存在台阶。原细化只沿当前候选向意图试探.5/.25/.125，评分台阶可阻止小幅连续改进。既有P5默认旋转中绕障样本83.3%落在原格点，107次提案>2°变化而原输入<.05rad；继承P3三轮慢扫中该格点比例86.2%/93.3%/87.7%。这些仅是动机，不能用继承数据替代本次P5性能对照。明细见 prior_motion_quantization.json。

.35s保持分支每帧重证，过期后再按评分选新方向，所以部分跳变间隔约.35s。保持本身历史上有收益，本候选保留其早返回、累计意图改变释放及直接意图优先语义；目标是改善每次重选的连续角度，不添加新的时间保持或响应延迟。

## 实现

新增 OmniDepthConfig.continuous_refinement=false。主线程仅在人工试验变体设true，固定目标不受该候选影响。

1. 开启时，角域余量仅在**评分**中使用周期双线性插值：方位跨±π相连，俯仰两端限制在极点。绝不插值自由证据或跳过未知检查。
2. 原离散搜索及原沿意图细化完成后，以已认证方向为中心，评估8个半格邻居（yaw±1°、pitch±2.5°），第二层步长再减半。
3. 只有当前评分严格改善、同前视障碍距离及可见条件满足，并且对该具体新方向重新调用原certify成功，才替换。每层至多采纳一个改进方向。
4. 每次调用计入原预算，完整总预算仍64；原直接意图/原已认证保持早返回不动。最终控制器仍做独立完整运动/制动证明。

## 已执行检查

- 扩展 omni_depth_check：原回归及新直接意图不变、已认证保持不变、每个输出有自己的认证、总预算、±π/上下极点、全拒绝及真实未知负例，exit0。
- 冻结旧函数与新函数关闭开关：96种不同深度/视角/缺帧/意图/保持配置，direction/clearance/observed/认证次数/保持/短视距状态逐项一致，96/96。
- 确定性缓慢移动可认证边界探针：旧/新40/40均可行；平均意图角误差 14.960959→14.235113°；最大相邻提案变化 2.991203→1.491203°；提案角二阶差分RMS 1.148799→0.540859 °/sample²；最多认证 26→32 次。该探针使用独立可行方向边界，是机制测试，**不是物理飞行jerk，也不是传感器完整闭环**。

首次新增未知负例失败：误用了原测试前段已经设置自由seed的PaperGuidance，因此接受seed内运动合法；修正为无seed独立认证器后通过。独立初稿探针出现未定义clamp编译错误，已用显式std::min/max修正；生产代码不涉及该名称。失败说明保留，不标记为真实飞行失败。

## 真实验收前置标准

主线程预先约定：同一新版controller下开关0/1、六特性关闭、callback执行源一致，jitter/spin/sweep各3对探索。实际jerk改善至少10%或平均角误差改善至少5%，其他指标按预定容差不退化，安全扫掠/外部保护必须0；通过才继续5对确认。比较到达/进展、停车、反向/松手响应、计算开销；若退化，从生产回退并保留本目录记录。不得用上述解析探针替代这一标准。
