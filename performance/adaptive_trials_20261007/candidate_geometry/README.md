# 精确几何证据查询优化：已探索，当前不进入生产

本轮冻结基线为`../baseline`，默认执行源callback、六项算法特征开关全关。只探索保持全部认证/决定不变的计算优化；没有改变安全半径、体素场景、7层/1024预算或证据顺序。

## 热点及代表性

冻结核心对P5已有卡停frame_0执行20次gprof：segmentDistance自耗约44.68%，envelopeKnownImpl内部covered扫描约27.92%，sphereObserved约19.37%；调和求解不是该例的主要耗时。gprof源对象在/tmp单独插桩并与冻结静态库链接，采样比例/多线程调用计数只定位热点，所有性能结论使用未插桩二进制。宿主perf_event_paranoid=4阻止perf，未修改系统设置。

近期默认目标运行仍有COMPUTE_DEADLINE，例如`p5_refine_execution_goals_20261007_before_ego1p5_2.log`：最终计算mean/P95/max为1.665/4.296/117.211ms。单次超时没有保存重放，因为现有捕获需要先连续3次拒绝。历史16卡停快照来自开启深度不确定性的渲染数据；该组不代表所有默认场景，另加入21个继承状态防止选择性报告。

原始热点在`../geometry_profile/`，本阶段`profile_evidence.json`保存索引与边界。

## v1：每次管包含查询加AABB预筛（失败并回退）

只在`tubeContains`先检查中心线AABB按剩余半径外扩，比较时向外计入大坐标浮点误差；不确定仍调用原投影/欧氏距离。4,807,776个随机、相切nextafter、退化、大数至1e300以及NaN/无穷输入，原/新判定差异0。

37帧×5交错batch，共185对完整输出逐字相同。16卡停P95 200.689→178.869ms，但21继承P95 314.100→449.707ms；全体mean157.943→189.941ms、P95 288.766→403.020ms。逐查询重算边界/guard在继承困难状态增加成本，验收失败。

已将生产函数恢复为冻结基线原实现。候选完整源`paper_guidance_v1.cpp`、二进制`paper_replay`、差分源及原始数据均保留；`v1_status.json`记录回退。根目录`replay_ablation.json`是v1失败数据，不可作为最终采用方案。

## v2完成时的历史线索（随后已实现为v3）

frame_3单次冻结gprof仍以segmentDistance58.4%、covered25.6%为主；约430个envelopeKnown调用触发约101万次covered/168万递归调度。frame_3/frame_4各有256条管、128个到达球、32个行经球、16份历史。相对P5卡停组，少量更大的根cube导致v2的一次粗筛仍保留太多管。

当时提出按八叉树层次继承并收紧管索引：每个子cube仅在父保留列表中筛分离管，保持原相对顺序及精确检查；列表很短时不再筛。当时只有设计，尚未实现或测试；为避免影响root的正式Isaac实验，CPU剖析和微基准暂时暂停。随后在Isaac全部结束后的独立CPU窗口实现并测试为v3，重新验证了递归中心覆盖、浮点余量、全部37帧决定和P95门槛；结果仍未达标，见下文v3及四版最终对照。该段保留提出方案时的历史背景，不表示当前仍待实现。

## 复现

`replay_ablation.py`及`v2/replay_ablation.py`用相同37快照、5次交错前后顺序、`OMP_WAIT_POLICY=PASSIVE`，每对即时保存stdout/stderr/退出码/墙钟/进程CPU，出现输出差异立即停并留档。已有输出不可覆盖。二进制使用原主构建O3、DNDEBUG、OpenMP编译参数；候选只替换一个paper_guidance对象，其余链接冻结静态库，未在计时中调用gprof。
