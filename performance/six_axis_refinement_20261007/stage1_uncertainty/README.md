# ①深度不确定性：保留原模型的原生遮挡扩张加速

状态：已实现并通过独立机制消融；整机导航收益未在本阶段运行。主构建、统一回归与记录由主任务汇总。

## 方案与约束

原算法在每个像素重复遍历 `(2r+1)²` 方形邻域，对每个邻点重复检查有限性和未知。该逻辑恰等价于：先把所有非有限值/非正值规范为未知0，再取方形邻域最小值；最小值为0或与中心的距离差严格超过阈值时，用该最小值。方形最小值可以先横向、再纵向计算，邻域工作量降为两次 `(2r+1)` 遍历。

保留sigma(z)=.005+.001z²、3sigma、.01m位姿界、原认证径向抵扣、同一方形边缘半径和严格阈值。按列/行预计算光轴余弦所需平方项，重复平方根仍逐像素进行以保持原值。未知邻域仍输出0；无空间平均、预测补洞或自由空间扩大。尺寸乘积改为size_t，避免非法大尺寸的有符号溢出。

## 逐项消融

测试内保留本轮冻结包中原函数的完整副本（仅改函数名），生产路径没有旧模型切换。651,857个随机/边界像素和2,764,800个原生微基准像素的结果位级完全一致；覆盖NaN、±inf、非正深度、单行/单列、半径0–4、阈值相等及相邻浮点值。另有7个非法尺寸/焦距/参数负例拒绝，关闭功能逐字节保持输入。

原1000次固定种子噪声检查仍为：原始高估488、保守高估0；物理碰撞位置错误机体通行认证8→0，启用.03m径向抵扣仍为0。原生边缘扩张占28个粗格，先降采样后扩张占42格。这些安全/覆盖结果与优化前相同，本次新增收益是计算开销。
