本轮在 EGO1P5 冻结现状上继续优化，前轮 74 个已见侧后方向认证能力保持。**实现阶段已通过；这里只证明缓存维护更快且保留相同证据，不宣称整机导航更快。** 主线程另做全链路构建与 Isaac 对照。

## 方案及安全条件

旧版已经按旧视锥对每个原生命中逐点预筛；同一帧的 76,800 个点仍要对每份历史观测重复矩阵变换、投影和取深度。本轮把连续 128 个世界坐标命中组织成包含全部点的轴对齐包围盒，先用区间上/下界判断整块是否不可能触发矛盾。块先经过旧相机的可见半空间，再用旧深度的全局最大值拒绝确定已在所有旧像素深度之后的块。余下点完整执行旧版的逐点预筛和 observedEnvelope(.03) 认证。

每个预筛都只判断原有认证的**必要条件**。盒子经过相机逆旋转后的中心/半宽为 c/h；每个视锥平面 n 若 n·c+|n|·h+数值余量 <= .03|n|，整块不可能被旧观测完整包含。深度上界条件沿用旧逐点必要条件：旧最大深度 <= 盒子最小 z + .03×全视锥最小光轴余弦 − 数值余量。先分别将盒子两端减去观测原点，再在局部坐标中计算中点/半宽；边缘余量按逆变换绝对值和各平面系数的绝对计算量设置 1e-10 比例上界，避免世界坐标中点消去及矩阵乘积项消去。数值非有限或无法肯定时回到逐点检查。

未改变 TTL=4s、年龄膨胀 .05m/s、方向桶、48份容量、原始观测出处或借用引用撤销逻辑；未把盲区未知空间认证为自由。接口和默认开关不变。

- src/pc_gvf/src/spherical_memory.cpp：128点块区间必要条件预筛。
- src/pc_gvf/test/cpp/spherical_ingest_check.cpp：160组确定种子 parity，检查留下的证据和已借出证据的撤销。

