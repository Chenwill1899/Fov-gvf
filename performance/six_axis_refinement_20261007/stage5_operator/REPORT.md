# ⑤ 操作体验滤波继续优化（2026-10-07）

本轮在冻结的前轮第二版上继续优化。**实际既有手柄输入的抖动段信号更平顺，冻结核心解析闭环命令变化更低；主线程尚需单独报告新一轮 Isaac 整体 jerk，不能提前说实际用户体验已经改善。**

## 定位与方案

前轮真实 Isaac 轨迹按阶段重算（previous_v2_phase_jerk.json）：抖动阶段实测速度 jerk RMS 两轮平均约 1.365→1.478 m/s³，慢转约 1.038→.953，逆向/松手等过渡主导全段数值。阶段分解与单频解析微扰的改善并不等价，不能仅用后者推断整体操作表现。

前轮方向滤波是单极 EMA：.875旧+.125新。对于已经识别到方向反转的小角振荡，本轮改为两级归一化 EMA，每级 α=2/9；小信号低频群延迟 2(1−α)/α=7 次更新，等于原单级(1−1/8)/(1/8)=7。高频方向加速度获得更强衰减。

只有原始操作者方向发生反转后才使用两级滤波。初始同向慢转保持原单极响应；连续三次有效同向变化恢复原始意图并清除振荡状态。重复输入不能积累同向次数。松手清空全部状态、大改向立即直通且重置两级状态、幅值原样保留。比较依然只用原始意图，不反馈避障输出；最大角误差门限仍 .018rad，更新后另查最终输出、必要时重置两级状态；固定目标及关闭开关路径不变。

## 同输入逐项消融

同一冻结 PaperGuidance 生产核心解析闭环（原 operator_intent_check 的600帧、机体/制动完整认证）：实际命令总变化 .0214314→.00663977，约减少69.0%；前进11.3518→11.3518m。未辅助同输入仍.241851/11.3515m，说明本轮比较确实是在旧辅助版与新辅助版之间，不把前轮关闭开关重当成本轮基线。

回归还覆盖三维混合频率抖动、重复输入、幅值保持、立即倒向/垂直分量、松手清空、再次起步及关闭开关原样直通。旧/新检查均 exit 0。结果保存在 measurements_v2_lag_bound/summary.json 和逐帧 CSV。

## 探索失败与限制

- 独立审查找到203步接近角阈值的输入：双极更新前虽未超限，滞后中间级仍可能将输出推远，最大 .018039772rad 超过原 .018rad 契约。已对最终输出补硬检查，超限时原样直通并重置两级状态；原反例最终最大 .017996310rad。反例保存 ../review/operator_lag_angles.txt，并新增 test/cpp/operator_lag_fixture.hpp 纳入正式回归。修复后全部同输入消融重跑，表中指标保持。原型 measurements_v1 保留，不替代最终证据。

- 初始双极滤波对所有小角变化生效，真实 fixture 的慢转意图 jerk 2.568059→2.589365，轻微退化；已改为仅振荡后使用，最终慢转逐样本完全一致。初始 fixture_metrics.json 保留。
- 初次独立核心检查退出139，回溯在 PaperGuidance 析构；原因是冻结库与其他并行修改后的公共头发生 ABI 混用。改用基线包完整头后，仅覆盖待测 OperatorIntent，旧新均通过。此为测试组织失败，不标记为飞行失败或掩盖。
- 尚无新实机、人类被试或本子任务独立 Isaac 证据；主线程负责最终整体对照。有限采样频率和确定性输入不能证明任意手柄噪声均改善。默认开关不变。
