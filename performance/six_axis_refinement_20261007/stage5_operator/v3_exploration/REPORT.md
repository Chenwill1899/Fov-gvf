# 正式六轮人工轨迹退化定位与 v3 方案筛选

结论：**不继续增强输入滤波；不采纳≤.05rad、.12s的提案小角保持候选。** 当前证据表明主要差异发生在必要避障提案变化、绕障后直接意图重捕获的执行阶段，以及松手末端的离散恒减速停止。没有修改生产源码，没有运行新 Isaac，也没有把离线信号改善冒充飞行改善。

## 数据与口径

来源：本轮 closed_loop/p5_refine_formal_operator_20261007 下 before/after 各3条、每条2042行CSV。`vx/vy/vz`为真实模拟速度，`applied_target_*`为本帧实际送入速度响应的目标；`target_*`为控制器提案，`input_*`为滤波后意图，`q*`为CSV本帧原始模拟操作者输入。

CSV诊断与执行通过独立ROS路径接收，`diagnostic_stamp`与`t`不同。因此已输出原始样本变化、滤波样本变化及±100ms原始变化上界；不把同一CSV行当成严格的DDS输入输出因果配对。二阶差分jerk与原汇总脚本一致。phase_metrics.json的初始阶段表包含相邻启停边界；refined_phase_metrics.json另拆边界，避免把14.983s的下一帧松手错误归因到稳定抖动。

输入滤波的信号收益在实际记录里成立，但没有自动传递为绕障输出的收益。慢转输入几乎相同，执行jerk仍不同，说明不能将整段差异都归因于滤波公式。

全段新增jerk平方和均值约 742.485，其中15.2–16s第一次松手终止约 287.704，占 38.7%。此阶段应用目标已恒为0；velocity_response采用1.2m/s²恒减速并在最后不足一步时截到0，微小初速度差异会改变末尾加速度跳变在1/2个样本间的分配。不能通过拖延松手、改变物理制动或专挑这个相位来优化指标。

## 提案跳变和小角滞回评估

完整时刻、角度、原输入变化和诊断时间戳见 proposal_jumps_4to8s.csv/json。初始4–8s统计9→10次>2°跳变是窗口边界效应：旧首个避障跳变在3.983s，新在4.000s。统一3.8–8s窗口后两组每轮均恰10次。新组总跳变角97.908/107.352/110.881°，旧组95.994/98.565/98.614°；不是多一次抖动，而是选中的路径和回收幅度略有差异。

中间提案跳变多为3.864–17.130°，间隔约.35s，与已有 goal_hold_time 到期重选相符。最后一跳旧组7.167–7.183s、新组7.200–7.333s，幅度28.4–30.4°，目标精确返回滤波意图。这是已有代码在当前意图走廊认证通过后直接优先回收，优先级高于短时保持；不能在没有旧方向仍可行的证据时阻拦。

主线程提出的“人工⑤、仍绕障、相邻提案≤.05rad、最多.12s保持且当前证据重新认证”的方案，仅覆盖旧组每轮1次、新组2/1/1次1.932°变化，均发生5.38–5.58s。它覆盖不到主要增加的7.3–7.6s回收执行尖峰，不值得在本次证据上贸然实现。资格细节见 small_proposal_hold_assessment.json。记录没有当前旧方向的corridor真值，不能将几何上符合小角门限等同于允许保持。

## 更有针对性的后续方案：统一命令接收与执行的新鲜度来源

根据既有trace的yaw_rate从applied_target还原body指令：4–8s重复前帧body命令旧35/240帧、新46/240帧；7.25–7.7s旧3/27、新6.33/27；慢转18–22.8s旧46.33/288、新61.67/288。重复本身不等于控制器没计算，故另对照诊断。

after_1可直接定位到：

|---|---:|---:|
| 7.5167 | .0440058075 | .0440058075 |
| 7.5333 | .0417211858 | .0440058075 |
| 7.5500 | .0386575796 | .0386575796 |
| 7.5667 | .0357289751 | .0386575796 |

中间已收到的诊断值未按均匀间隔执行；7.5333s形成9.95m/s³实际jerk。详细还原数据在 body_repeat_analysis.json。这里仍无法仅凭CSV确认延迟发生于控制器到Twist桥、Twist订阅，还是OmniGraph更新。

代码确有值得修正的数据来源分离：run_fov_gvf_navigation.py的rclpy `/sim/cmd_vel`回调只更新`last_twist_wall`，实际向量却从另一个`ROS2SubscribeTwist(queueSize=2)`读出。新的接收时间可能为另一路旧向量通过dead-man检查。

建议以独立执行源开关做实验：同一Twist回调原子保存向量、接收时间与序号，帧执行直接读取这一对并记录应用序号；仍保留.10s过期归零、物理松手立即0、原动力学及完整运动/制动安全证明。不插值未知命令，不减小制动强度，不把避障输出当成人工意图。该方案首先修正新鲜度与向量不一致，并能验证重复/跨步来源；是否改善实际jerk必须用相同算法配置和旧/新执行源交错闭环确认。属于Isaac执行桥工作，超出本子任务原operator头职责，未自行实施。
